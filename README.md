# 💖 Ask-Out: The "No-Proof" Question Generator

A playful and interactive web application that makes saying "No" impossible! Whether it's a date, a favor, or a simple prank, this tool ensures the answer is always **Yes**.

![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)
![Developed by Obed](https://img.shields.io/badge/Developed%20by-Obed-ff4d6d)

## 🚀 Features

* **Evasive "No" Button:** Try to click "No," and it jumps to a random spot on the screen!
* **Dynamic Scaling:** Every time the user attempts to click "No," the "Yes" button grows larger until it takes over the screen.
* **Link Generator:** An open platform where anyone can enter names and a custom question to generate a unique sharing link.
* **WhatsApp Integration:** Share your generated "trap" directly to WhatsApp with one click.
* **Universal Success:** A friendly "I knew you'd say yes!" message regardless of the question.
* **Responsive Design:** Works perfectly on both Desktop and Mobile.

## 🛠️ Tech Stack

- **HTML5** & **CSS3** (Custom UI/UX)
- **JavaScript** (DOM Manipulation & Logic)
- **Canvas-Confetti** (Celebration effects)
- **URL Search Params** (To handle data without a database)
